# 宝宝看护器知识入口

## 型号范围

当前看护器知识覆盖四个型号：

- `hb_monitor_4`：海马爸比宝宝看护器4代，定位为隐私・画质全能王。
- `hb_monitor_2_refresh`：海马爸比宝宝看护器2代焕新版，定位为性价比之王。
- `hb_monitor_2_plus`：海马爸比宝宝看护器二代 PLUS，定位为 4K 性价比之选。
- `hb_monitor_3`：海马爸比宝宝看护器三代旗舰版，定位为科技力之王。

## 检索路径

- 用户问型号参数：先查 `10_products/monitor/models/` 下对应产品文档。
- 用户问对比：查 `10_products/monitor/monitor_specs_matrix.md` 和 `10_products/monitor/monitor_feature_matrix.yaml`。
- 用户问配件适配：查 `10_products/monitor/monitor_compatibility_matrix.yaml`。
- 用户问安装：查 `20_intents/03_installation_settings.md`。
- 用户问配网、离线、不出画面：查 `20_intents/02_connection_pairing.md`。
- 用户问回看、录像、SD 卡、通知、夜视、小夜灯、对讲、音乐：查 `20_intents/04_function_usage.md`。
- 用户问 AI、云台跟随、睡眠报告、呛奶/呼吸边界：查 `20_intents/04_function_usage.md` 和 `00_global/customer_service_boundaries.md`。

## 回答提醒

- 用户只说“四代”“二代”“黄色款”等口语化名称时，先用 `../aliases.yaml` 做别名归一。
- 三代分辨率按 `2880 x 1620` 回答，尺寸按 `137 x 88 x 108 mm` 回答。
- 看护器不能替代成人看护或医疗判断。
