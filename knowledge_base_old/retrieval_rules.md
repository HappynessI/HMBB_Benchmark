# 检索与冲突处理规则

## 产品识别

1. 用户提到“四代”“4代”“高清款打印机”“云朵贴”等口语化名称时，先查 `aliases.yaml`。
2. 能识别到具体产品时，优先读取该产品专属文档。
3. 不能识别具体型号且不同型号答案可能不同，应先追问型号，不要直接套用某一型号参数。

## 文档优先级

1. 具体产品参数：产品专属文档优先。
2. 型号对比：`10_products/monitor/monitor_specs_matrix.md` 和 `10_products/monitor/monitor_feature_matrix.yaml` 优先。
3. 配件兼容：`10_products/monitor/monitor_compatibility_matrix.yaml` 优先。
4. 操作步骤：对应 topic 文档优先。
5. 安全、售后、医疗边界：`20_intents/05_service_safety.md` 和 `00_global/customer_service_boundaries.md` 优先。
6. `_archive/legacy/` 文档仅作历史参考，不作为优先答案来源。

## 来源与归因

1. 官方说明书、官网 FAQ、商品详情页、用户补充客服问答需要在文档元数据或清单中标明来源层级。
2. 价格、销量、赠品等电商信息只表示采集时页面显示，不承诺实时有效。
3. 回答价格时使用“页面显示”“当前知识库记录”这类表述，避免承诺最终成交价。

## 冲突处理

1. 产品硬件参数优先级：官方说明书 > 官网产品页 > 电商详情页 > 客服问答 > 用户评论。
2. 同一来源内部出现参数冲突时，必须保留冲突说明，不要擅自合并成单一确定值。
3. 三代看护器分辨率按 `2880 x 1620` 回答，产品尺寸按 `137 x 88 x 108 mm` 回答。
4. 配件只写明适配某型号时，不能推断适配其它型号；不确定时答“建议按购买页面具体变体确认”。

## 安全与医疗边界

1. 看护器是辅助看护设备，不能替代成人看护或医疗设备。
2. 对呛奶、呼吸异常、发热、窒息风险等问题，不能让用户只依赖设备判断。
3. 若宝宝出现异常表现，应建议家长及时人工查看；严重或持续异常时及时就医。
4. 小夜灯、声音、对讲等功能应提醒用户避免长时间、近距离直射或高音量刺激宝宝。

## 找不到依据

1. 不允许编造参数、版本、保修、兼容范围。
2. 知识库没有明确写明时，应说明“当前知识库没有明确依据”，再给出可验证的下一步。
3. 可以建议用户提供商品链接、订单页截图、设备型号或 APP 页面截图以便确认。
