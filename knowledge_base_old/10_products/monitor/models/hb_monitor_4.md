## 四代专项问答口径

| 用户问题 | 客服回答 |
|---|---|
| 四代夜间有灯光吗？ | 有。设备夜间配有小夜灯，灯光较柔和，方便夜间辅助看护宝宝。 |
| 四代小夜灯会不会影响宝宝视力？ | 小夜灯为柔和灯光设计，正常使用主要用于夜间辅助看护。建议避免让灯光近距离、长时间直射宝宝眼睛，并根据实际环境调节使用。 |
| 四代可以 360 度无死角看护吗？ | 设备支持通过 APP 调节看护角度，安装位置较高时可以扩大可视范围。实际看护范围会受到安装高度、摆放位置、遮挡物和房间布局影响，不要承诺绝对无死角。 |
| 四代适合孩子会走动、会跑动的场景吗？ | 可以用于孩子活动场景下的看护。设备支持转动看护，能够根据画面情况进行跟随，方便观察宝宝活动状态。 |
| 四代看护器可以随身带走使用吗？ | 设备本质上是宝宝看护/监控设备，可以根据使用场景移动摆放，但需要保证供电、网络连接和安装位置稳定，才能正常使用。 |
| 四代会跟着孩子转动吗？ | 支持云台转动/跟随类看护功能，可用于观察宝宝移动情况。实际跟随效果会受网络、安装位置、环境遮挡和宝宝移动速度影响。 |
| 四代有呼吸监测功能吗？ | 支持呼吸频率、睡眠质量等相关监测功能，具体功能以购买版本和 APP 页面显示为准。 |
| 四代可以监测宝宝是否呛奶吗？ | 不能将其作为判断宝宝是否呛奶的专业设备。设备可用于辅助观察宝宝状态，部分版本支持呼吸频率或睡眠相关记录，但无法替代家长看护或医疗判断。 |
| 四代能预防宝宝呛奶吗？ | 设备不能直接预防呛奶。建议家长注意喂奶后的拍嗝、睡姿和侧身观察等日常护理方式；如宝宝出现异常情况，应及时人工查看或就医。 |
